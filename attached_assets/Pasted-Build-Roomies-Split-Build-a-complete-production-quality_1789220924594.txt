Build: Roomies Split

Build a complete, production-quality web application called Roomies Split from scratch.

There is no existing source code to reuse.

The app is a smart receipt-based bill splitting application designed primarily for mobile users.

The core idea:

«Snap a receipt. We read the items. You tell us who had what. We split the bill.»

The application should feel dramatically easier than manually entering every item into a bill-splitting app.

---

1. PRODUCT PRINCIPLES

The application must be:

- Mobile-first
- Extremely easy to use
- Fast
- Clean and modern
- Responsive
- Accessible
- Designed primarily for Indian users
- Currency default: INR (₹)
- Suitable for groceries, restaurant bills, household purchases, shopping receipts, etc.
- No unnecessary account creation for basic usage
- No complicated onboarding

Do not over-engineer the UI.

The user should be able to go from receipt photo → final split in roughly a minute.

The AI should extract structured information rather than simply returning OCR text.

Extract:

- Address if available
- Date
- Time
- Bill/receipt number if available

Items

For every item extract:

- Item name
- Quantity
- Unit
- Unit price
- Total price
- Discount
- Tax if available
- SKU/product code if available
- Confidence

Understand common receipt formats such as:

- "2 PCS"
- "2 NOS"
- "5 KG"
- "500 G"
- "1.25 KG"
- "2 L"
- "750 ML"
- "6 × ₹14"
- "₹120/KG"
- "₹80/100G"

Correctly distinguish:

quantity × unit price = item total

from a receipt where the displayed number is already the line total.

Support Indian receipt terminology such as:

- CGST
- SGST
- IGST
- GST
- CESS
- Round Off

9. ITEM ASSIGNMENT

This is the heart of the application.

For each receipt item, ask:

Who had this?

Every item should support three modes.

Mode 1 — One person

Example:

Aashirvaad Atta — 5 KG — ₹310

→ Surajith

The entire item is assigned to Surajith.

---

Mode 2 — Shared equally

Example:

Milk — 4 × 500 ML — ₹240

→ Surajith
→ Arun
→ Rahul

The application splits the item equally.

---

Mode 3 — Custom quantity

Example:

Milk — 4 × 500 ML

Surajith → 2
Arun → 1
Rahul → 1

The application calculates:

Surajith = ₹120
Arun = ₹60
Rahul = ₹60

For weight-based products:

Apple — 1.25 KG — ₹175

Allow:

Surajith → 0.75 KG
Arun → 0.50 KG

Calculate proportionally.

16. ROUNDING

Money calculations must be deterministic.

Always reconcile the final individual amounts with the receipt total.

Example:

Receipt total:

₹1,000.00

People:

A → ₹333.33
B → ₹333.33
C → ₹333.34

Total:

₹1,000.00 ✓

Never leave a ₹0.01/₹0.02 unexplained discrepancy.

Use a predictable rounding strategy and display it transparently if necessary.
